usage: build_preset_docs.py [-h] [--check] [--pages [DIR]]
                            [--format {markdown,json}]

Build preset documentation

options:
  -h, --help            show this help message and exit
  --check               Check whether the preset names module, preset-powered
                        quick-start examples, and README support lists are up
                        to date (preset_names.py, docs/getting-started.md, and
                        generated sections in README.md and the FastAPI server
                        page); the preset pages are built at deploy and not
                        compared
  --pages [DIR]         Write only the preset pages (presets.md, preset-
                        history.md) into DIR (default: docs/), as the docs
                        deploy does
  --format {markdown,json}
                        Print presets in the selected format instead of
                        writing docs
