Add the runtime dependencies of server to your project:
  uv add "fastapi>=0.141.1" "pydantic>=2.14.0" "typing-extensions>=4.16"
Next steps: implement the stubs in {project}/services/pets.py, {project}/services/store.py, then run the server:
  uv add uvicorn && uv run uvicorn --app-dir {project} server.main:app --reload
or: uv add "fastapi[standard]" && uv run fastapi dev {project}/server/main.py
See {project}/server/README.md.
