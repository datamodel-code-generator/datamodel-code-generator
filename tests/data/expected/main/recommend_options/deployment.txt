Add (1 option)
  --class-name Deployment   [root.class-name-for-root-object]
      The root schema is an object model. Without --class-name its class is Model (with
      --use-title-as-name, its title: Deployment), and full-path prefixes that name onto root-level
      models. The suggested name comes from the input file name; replace it with the name the
      project wants.
      measured: SchemaStore tsconfig schema: JSONSchemaForTheTypeScriptCompilerSConfigurationFile
      became TsConfig, names over 40 characters 6 -> 0
      measured: SchemaStore workflow, docker-compose and package.json schemas: Model became
      Workflow, Compose and PackageJson

Optional (validation; not in the command)
  --generate-schema-validators   [validation.check-unique-items-and-pattern-properties]
      The models leave out checks the schema declares (uniqueItems: 0; patternProperties: 2):
      duplicate items pass, and patternProperties is checked on plain maps only, not next to
      declared properties. The experimental schema validators check both when a model validates.
      caveat: The option is experimental: on some measured schemas the validators rejected valid
      documents or the models failed to import, and class names can change; generate with it and
      validate your own documents before adopting it.
