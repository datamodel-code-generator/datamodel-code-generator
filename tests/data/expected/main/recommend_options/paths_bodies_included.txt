Add (1 option)
  --openapi-as-definitions paths-bodies ref-components   [openapi.paths-bodies-as-definitions]
      Request or response bodies of the paths or webhooks scope are object schemas that generation
      types inline although their schema definitions get models (1), such as a type array [object,
      null]. With them modeled as definitions, each body gets that model, and a document whose only
      bodies are such schemas generates models instead of failing with 'Models not found in the
      input data'. The same principle gives a component written as a $ref to a recursive schema with
      sibling keywords the root model a definitions entry of that schema gets, as the 20261027
      presets do.
      measured: OpenAPI request body {type: [object, null], additionalProperties: {...}} under
      --openapi-scopes paths: 'Models not found in the input data' without the option, a
      PetsPostRequest root model of dict[str, ...] | None with it
      measured: OpenAPI response body of the same shape: 'Models not found in the input data'
      without the option, a PetsGetResponse root model with it
      measured: nullable_map_value_types.yaml test input: the POST /scores request body [object,
      null] gains ScoresPostRequest; every other model is unchanged

Optional (policy; not in the command)
  --strict-types int float bool   [policy.strict-scalar-types]
      Pydantic validates in lax mode, which coerces input into the 1 integer, number and boolean
      schemas: it accepts the string "5" and true as integers, "1.5" as a number, and "true" or 1 as
      booleans. Strict types reject such input. Whether to accept it depends on the project's
      clients, not on the schema; strict int also rejects 5.0, which JSON Schema counts as an
      integer, so leave int out to accept it.
      measured: 11 JSON documents for integer, number, boolean and string properties, 6 of them
      invalid: lax mode accepted 5 invalid ones; with int float bool, 0 accepted and 1 valid one
      rejected (5.0 as an integer); with float bool, 2 accepted ("5" and true as integers) and none
      rejected
