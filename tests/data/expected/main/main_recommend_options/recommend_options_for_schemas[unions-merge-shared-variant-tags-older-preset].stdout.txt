Add (1 option)
  --merge-shared-variant-tags   [unions.merge-shared-variant-tags]
      Discriminated unions tag 2 variants differently, for example one by a mapping key and one by
      the schema name. A variant has one tag field, so without merged tags it keeps the tags of the
      first union, and the other union rejects every document that selects the variant by its own
      tag; merged, the variant takes every tag its unions give it.
      measured: #5361: Cat listed by ByName (tag Cat) and ByKey (mapping key cat); without the
      option ByKey rejected {"kind": "cat"}, with it Cat takes Literal['Cat', 'cat'] and both unions
      decode their documents
      measured: #4666: a variant two discriminator mappings tag differently; with the option each
      union decodes its own tag
