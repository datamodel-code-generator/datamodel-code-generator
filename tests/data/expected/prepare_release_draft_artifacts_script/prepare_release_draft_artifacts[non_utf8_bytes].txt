## Release Baseline

Baseline release: 0.1.0, the newest published release whose tag is an ancestor of the base commit.
These experimental features, command-line options, presets and public Python names are present at the merge commit and absent at 0.1.0, so no release has them:

```text
Experimental features:
  behavior.new (target requirement('extra'))
Command-line options:
  --new
  --no-new
Presets: none
Public Python names:
  NewName
```
