# API 日本 {braces}

The `server` package serves the API 日本 {braces} API with FastAPI.
datamodel-code-generator generated it from the OpenAPI document, together with the `models` models of the `pydantic_v2.BaseModel` backend.
Every file of the package belongs to the generator: keep your code in your own modules and regenerate the package instead of editing it; see [Regenerating](#regenerating).

FastAPI server generation is experimental.
The server supports the `pydantic_v2.BaseModel` and `pydantic_v2.dataclass` model backends, while client generation supports all five.
Custom templates, base classes, and Python types stay within these two backends.

## Operations

| Service | Method | HTTP method | Path | Operation key |
| --- | --- | --- | --- | --- |
| `Pets` | `get` | GET | `/pets/{id}` | `get` |
| `Pets` | `create` | POST | `/pets` | `create` |

`operation_dependencies` takes the operation keys, the values of `OperationKey`.

## Implementing the services

`services.py` declares a Protocol for each router group, with an abstract method for each operation of the group.
A method takes the operation's arguments as keywords, with `None` for an optional parameter or body the request omits, and returns the value to send, an `HTTPResult` with another declared status, headers, or both, or a `Response` sent as it is.
Implement each group in a module of your own and pass an instance to `create_app` under the group's name.
Subclass the Protocol, so that type checkers report a missing or mismatched method and Python refuses to create an instance while a method is missing; any other object with the same methods is checked where you pass it.
The Protocols of groups with secured operations take the type of the principal your `authorize` callback returns.

```python
from server import Credentials, RequirementSets, create_app
from server.services import Pets, Other


class PetService(Pets[Principal]):
    """Implement get and create."""


class OtherService(Other):
    """Implement list."""


def authorize(requirement_sets: RequirementSets, credentials: Credentials) -> Principal:
    ...


app = create_app(pets=PetService(), authorize=authorize)
```

Run the application with any ASGI server, such as `uvicorn app:app` for a module named `app.py`.
`create_app` passes its other keyword arguments, such as `lifespan`, `middleware`, or `dependencies`, to `FastAPI`, over the title, version, and other metadata of the source document.
To keep your own `FastAPI` application, include the router:

```python
from fastapi import FastAPI

from server import build_router

app = FastAPI(lifespan=lifespan, exception_handlers=exception_handlers)
app.include_router(build_router(pets=PetService(), authorize=authorize))
```

## Authentication

The secured operations use these security schemes:

- `bearer`: bearer token
- `api_key`: API key

`security.py` declares one FastAPI dependency for each scheme; replace one with `app.dependency_overrides`, for example to read a scheme no FastAPI class reads.
Each secured operation calls `authorize` once with its requirement sets whose every scheme presented a credential, in declaration order, and the credentials by scheme name, and receives the principal it returns.
`authorize` checks the credentials, tokens, and scopes, and rejects a request by raising `HTTPException`, such as `403`; it may be a coroutine function.
A request that presents no complete requirement set answers `401`, unless the operation also accepts no credentials, in which case it receives `None`.
The package never contacts a token endpoint.

## Served OpenAPI document

The application serves FastAPI's own document, built from the routes and the models they declare.
An optional parameter or request body is declared as `T | None = None`, so its schema there is `anyOf` of the type and `null`.
Each route adds what FastAPI cannot derive from it, taken from the source document when the package is generated: the declared responses, and the parameters, request bodies, and callbacks that adapters read, with their schemas' references resolved in place.

## Validation

The models are the contract: FastAPI validates parameters, bodies, and responses with the generated model types, so the model generation settings decide how strictly a value follows the OpenAPI document.
Parameter styles, parameter types, and media types that FastAPI cannot read, such as deepObject or form-style cookie parameters, strict integers, numbers, and booleans, text and binary bodies, and multipart forms, pass through generated adapters.
An adapter parses the HTTP syntax, then validates the value with the model's `TypeAdapter`; it answers `400` for malformed syntax, `415` for an undeclared media type, and `422`, with FastAPI's error records, for an invalid value.
Native parameters follow FastAPI, which takes the last value of a repeated single-valued query parameter and the first of a repeated header; parameters read through adapters reject both with `400`.
URL-encoded form bodies are FastAPI form models, so FastAPI's form extraction applies; set the operation's `body_modes` entry to `request` when the exact submitted values matter.
Operations with the `request` body mode receive the Starlette `Request` and read and validate their body themselves.

## Regenerating

Run the same generation again whenever the OpenAPI document changes; the `--check` option, or `render_fastapi`, reports the files it would change without writing them.
Generation rewrites every file it owns, restoring any you edited or deleted, and never touches your own modules.
When an operation is added, removed, or changed, its method in `services.py` changes with it, so type checkers point at the implementations to update, and Python refuses to create an instance of a subclass that lacks a new method.
Each generation prints the `uv add` command that adds the runtime dependencies of the package to your project;
run it again when a new version of datamodel-code-generator changes them.

from fastapi import APIRouter


def add_get(router: APIRouter, wiring: Wiring) -> None:
    handle_get = wiring.async_handlers["get"]

    async def principal() -> str:
        return "principal"

    async def get(*, pet_id: int) -> Pet:
        return await handle_get(pet_id=pet_id)

    router.add_api_route("/pets/{pet_id}", get, methods=["GET"])


def add_list(router: APIRouter, wiring: Wiring) -> None:
    handle_get = wiring.async_handlers["get"]

    async def get(*, pet_id: int) -> Pet:
        return await handle_get(pet_id=pet_id)

    router.add_api_route("/pets/{pet_id}", get, methods=["GET"])


LITERAL_ROUTES: Final = (add_list,)

def build_router(*, pets: Pets):

    return build(
        (*LITERAL_ROUTES, *TEMPLATED_ROUTES),
        services={"pets": pets},
